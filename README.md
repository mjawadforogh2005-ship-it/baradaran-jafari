# وب‌سایت تبلیغاتی حواله آریا

یک وب‌سایت مدرن، ریسپانسیو و کامل برای خدمات حواله پول بین‌المللی.

## ویژگی‌ها

- طراحی تیره و حرفه‌ای با فونت وزیرمتن
- پشتیبانی کامل از راست‌چین (RTL)
- دکمه‌های شناور واتساپ و تلگرام در همه صفحات
- لینک مستقیم واتساپ و تلگرام در هدر، فوتر، مراکز و بخش تماس
- جدول نرخ خرید و فروش ارز لحظه‌ای (از API رایگان)
- مبدل سریع ارز در صفحه اصلی
- بخش مراکز خدمات در چند کشور
- بخش خدمات، درباره ما و تماس
- کاملاً موبایل‌فرندلی

## چگونه استفاده کنید؟

1. فایل‌های داخل پوشه `havale-website` را روی هاست خود آپلود کنید.
2. **حتماً** شماره‌ها و آیدی‌ها را تغییر دهید:

### تغییر شماره واتساپ
در فایل‌های زیر، `989123456789` را با شماره واقعی خود جایگزین کنید (بدون + و صفر اول):

- `index.html` (چند جا)
- `js/main.js` (بالای فایل)

مثال: اگر شماره شما `+98 912 111 2233` است → بنویسید `989121112233`

### تغییر آیدی تلگرام
در فایل‌های زیر، `AriaHavale` را با آیدی واقعی تلگرام خود جایگزین کنید:

- `index.html`
- `js/main.js`

### تغییر نام کسب‌وکار
در `index.html` جستجو کنید و «حواله آریا» را به نام دلخواه تغییر دهید.

### تغییر مراکز خدمات
در بخش `#centers` داخل `index.html` آدرس‌ها، تلفن‌ها و شهرها را ویرایش کنید.

### نرخ ریال و افغانی
در `js/main.js` داخل آبجکت `manualRates` و `extra` اعداد تقریبی را با نرخ واقعی روز خود جایگزین کنید (چون APIهای رایگان معمولاً ریال ایران را پوشش نمی‌دهند).

## اجرا به صورت محلی

می‌توانید با هر سرور استاتیک ساده اجرا کنید:

```bash
# با Python
cd havale-website
python3 -m http.server 8080
```

سپس در مرورگر باز کنید: http://localhost:8080

## نکات مهم

- نرخ‌های نمایش‌داده‌شده **تقریبی** هستند و برای جلب اعتماد مشتری طراحی شده‌اند.
- همیشه قبل از تراکنش، نرخ نهایی را از طریق واتساپ/تلگرام اعلام کنید.
- این سایت صرفاً تبلیغاتی است و سیستم پرداخت آنلاین ندارد.
